本政策的適用範圍

本政策適用於 ducknap.games、其 www 網址及 GitHub Pages 鏡像網站上的 Duck Nap Games 工作室網站，不適用於我們的遊戲或瀏覽器試玩版的資料處理方式。

以 Duck Nap Games 名義營業的 Mirheydar Badirov，對網站營運者所處理的個人資訊負責。如有問題或隱私權請求，請寄信至 ducknapgames@gmail.com。

託管與連線資訊

造訪網站時，我們的網頁伺服器及託管服務可能處理你的 IP 位址、請求時間、請求的網址、瀏覽器資訊、回應狀態，以及瀏覽器有傳送時的來源網站。這些紀錄有助於提供網站內容、診斷錯誤，並保護服務免受濫用。

我們不會利用這些營運紀錄建立廣告個人檔案，或在不相關的網站間追蹤你。請勿將密碼或敏感個人資訊放入網址或查詢參數。

GitHub 表示，基於安全目的，GitHub Pages 的造訪紀錄會包含訪客 IP 位址。該資料的處理方式詳見 GitHub 自身的隱私權資訊。

Cookie 與儲存的偏好設定

我們不設定廣告或分析用 Cookie。若你選擇淺色或深色模式，網站會以 ducknap-theme 為名稱，將偏好設定儲存在瀏覽器的本機儲存空間。這不是訪客識別碼，也不會作為分析事件傳送給我們。瀏覽器語言及系統外觀會在你的裝置上用於建議語言與主題設定。清除此網站的瀏覽器儲存空間，即可移除已儲存的偏好設定。

網站統計

我們根據成功的頁面請求，自行產生網站統計。彙總前，會將請求資訊縮減為已知的頁面路徑，以及根據來源資訊或已識別的 utm_source 判定的大類流量來源。我們保留每日總計 90 天，不保留個別請求紀錄。這些統計不儲存 IP 位址、訪客識別碼、完整來源資訊、原始瀏覽器資訊或任意查詢參數，也不使用 Cookie 或追蹤指令碼。已知機器人及傳送 Do Not Track 或 Global Privacy Control 的請求均會排除。數字代表頁面瀏覽次數，而非不重複人數；重新載入會再次計入，來源資訊也可能缺漏。儀表板不對外公開，並限制存取權限。這些統計涵蓋 ducknap.games，不包含 GitHub Pages 鏡像網站。

我們可能查看 Google Search Console 的彙總報告，了解網站在 Google 搜尋中的曝光情況，例如曝光次數與點擊次數。這些報告不會向我們提供個別訪客的身分，也不需要在本網站安裝訪客追蹤指令碼。

你傳送給我們的訊息

若你寄信給我們，我們會收到你的電子郵件地址、訊息，以及你選擇傳送的附件。我們使用 Gmail 處理往來郵件，並利用這些資訊回答問題、討論合作或回應隱私權請求。請勿傳送密碼、付款卡資料或不必要的敏感資訊。

目的與法律依據

若適用的資料保護法要求法律依據，我們會基於提供正常運作且安全的網站，以及回應訊息的正當利益處理資訊。我們也會在履行法律義務所需時處理資訊。我們不出售個人資訊，也不利用網站往來郵件進行具有法律或類似重大影響的純自動化決策。

保留、供應商與安全

技術性連線紀錄依託管服務的營運及安全要求保留，包括排解問題及調查事件所需的紀錄。我們會在處理請求及任何相關爭議或法律義務所需期間保留往來郵件，不再需要時即刪除。保留期限取決於目的、事件調查或爭議持續的時間，以及適用的法律義務。對於與你的請求相關的紀錄，你可向我們詢問適用的保留期限或決定標準。

我們的網頁託管服務會處理技術性連線紀錄。使用 GitHub Pages 鏡像網站時，GitHub 會處理資料；Google 則處理 Gmail 往來郵件及 Search Console 服務。這些供應商可能在你所在國家以外處理資訊，包括歐洲經濟區（EEA）以外。其隱私權資訊會說明適用的保留方式、保障措施及傳輸安排。我們限制營運紀錄與往來郵件的存取，並以 HTTPS 提供網站連線；任何系統都無法保證絕對安全。
