ขอบเขตของนโยบายนี้

นโยบายนี้ครอบคลุมเว็บไซต์สตูดิโอ Duck Nap Games ที่ ducknap.games ที่อยู่แบบ www และเว็บไซต์สำเนาบน GitHub Pages ไม่ครอบคลุมแนวปฏิบัติด้านข้อมูลของเกมหรือเวอร์ชันทดลองบนเบราว์เซอร์ของเรา

Mirheydar Badirov ซึ่งดำเนินกิจการในชื่อ Duck Nap Games รับผิดชอบข้อมูลส่วนบุคคลที่ผู้ดำเนินเว็บไซต์จัดการ หากมีคำถามหรือคำขอด้านความเป็นส่วนตัว โปรดส่งอีเมลถึง ducknapgames@gmail.com

โฮสติ้งและข้อมูลการเชื่อมต่อ

เมื่อคุณเยี่ยมชม เว็บเซิร์ฟเวอร์และบริการโฮสติ้งของเราอาจประมวลผลที่อยู่ IP เวลาที่ส่งคำขอ ที่อยู่เว็บที่ร้องขอ ข้อมูลเบราว์เซอร์ สถานะการตอบกลับ และเว็บไซต์ต้นทางเมื่อเบราว์เซอร์ส่งข้อมูลนั้นมา บันทึกเหล่านี้ช่วยให้บริการเว็บไซต์ วินิจฉัยข้อผิดพลาด และปกป้องบริการจากการใช้งานในทางที่ผิด

เราไม่ใช้บันทึกการดำเนินงานเหล่านี้สร้างโปรไฟล์เพื่อโฆษณาหรือติดตามคุณข้ามเว็บไซต์ที่ไม่เกี่ยวข้องกัน โปรดอย่าใส่รหัสผ่านหรือข้อมูลส่วนบุคคลที่อ่อนไหวในที่อยู่เว็บไซต์หรือพารามิเตอร์คำค้นของ URL

GitHub ระบุว่าบันทึกการเข้าชม GitHub Pages พร้อมที่อยู่ IP ของผู้เข้าชมเพื่อความปลอดภัย ข้อมูลความเป็นส่วนตัวของ GitHub อธิบายวิธีจัดการข้อมูลดังกล่าว

คุกกี้และการตั้งค่าที่บันทึกไว้

เราไม่ตั้งค่าคุกกี้สำหรับโฆษณาหรือการวิเคราะห์ หากคุณเลือกโหมดสว่างหรือโหมดมืด เว็บไซต์จะบันทึกการตั้งค่านั้นในพื้นที่จัดเก็บในเครื่องของเบราว์เซอร์โดยใช้ชื่อ ducknap-theme ค่านี้ไม่ใช่ตัวระบุผู้เข้าชม และไม่ถูกส่งมาถึงเราเป็นเหตุการณ์การวิเคราะห์ ภาษาเบราว์เซอร์และรูปแบบการแสดงผลของระบบใช้บนอุปกรณ์ของคุณเพื่อแนะนำการตั้งค่าภาษาและธีม คุณลบการตั้งค่าที่บันทึกไว้ได้โดยล้างข้อมูลที่เบราว์เซอร์จัดเก็บสำหรับเว็บไซต์นี้

สถิติเว็บไซต์

เราจัดทำสถิติเกี่ยวกับเว็บไซต์ด้วยระบบของเราเองจากคำขอหน้าเว็บที่สำเร็จ ก่อนรวมยอด ข้อมูลคำขอจะถูกลดเหลือเพียงเส้นทางหน้าเว็บที่ระบบรู้จักและกลุ่มแหล่งที่มาของการเข้าชมแบบกว้าง ๆ ซึ่งระบุจากข้อมูลเว็บไซต์ต้นทางหรือค่า utm_source ที่ระบบรู้จัก เราเก็บยอดรวมรายวันไว้ 90 วัน ไม่ใช่บันทึกคำขอแต่ละรายการ สถิติเหล่านี้ไม่เก็บที่อยู่ IP ตัวระบุผู้เข้าชม ข้อมูลเว็บไซต์ต้นทางแบบเต็ม ข้อมูลเบราว์เซอร์ดิบ หรือพารามิเตอร์คำค้นที่ไม่ได้กำหนดไว้ และไม่ใช้คุกกี้หรือสคริปต์ติดตาม เราไม่นับบอตที่ระบบรู้จักหรือคำขอที่ส่ง Do Not Track หรือ Global Privacy Control ตัวเลขคือจำนวนการดูหน้าเว็บ ไม่ใช่จำนวนคนแบบไม่ซ้ำ การโหลดหน้าใหม่จะถูกนับอีกครั้ง และอาจไม่มีข้อมูลแหล่งที่มา แดชบอร์ดไม่เปิดเผยต่อสาธารณะและจำกัดสิทธิ์การเข้าถึง สถิติเหล่านี้ครอบคลุม ducknap.games ไม่รวมเว็บไซต์สำเนาบน GitHub Pages

เราอาจดูรายงานภาพรวมจาก Google Search Console เกี่ยวกับการปรากฏของเว็บไซต์ใน Google Search เช่น จำนวนการแสดงผลและการคลิก รายงานเหล่านี้ไม่เปิดเผยตัวตนของผู้เข้าชมแต่ละรายให้เรา และไม่จำเป็นต้องมีสคริปต์ติดตามผู้เข้าชมบนเว็บไซต์นี้

ข้อความที่คุณส่งถึงเรา

หากคุณส่งอีเมล เราจะได้รับที่อยู่อีเมล ข้อความ และไฟล์แนบที่คุณเลือกส่ง เราใช้ Gmail จัดการการติดต่อ และใช้ข้อมูลเพื่อตอบคำถาม พูดคุยเรื่องความร่วมมือ หรือจัดการคำขอด้านความเป็นส่วนตัว โปรดอย่าส่งรหัสผ่าน รายละเอียดบัตรชำระเงิน หรือข้อมูลอ่อนไหวที่ไม่จำเป็น

วัตถุประสงค์และฐานกฎหมาย

เมื่อกฎหมายคุ้มครองข้อมูลที่ใช้บังคับกำหนดให้มีฐานกฎหมาย เราอาศัยประโยชน์โดยชอบด้วยกฎหมายในการให้บริการเว็บไซต์ที่ทำงานได้และปลอดภัย รวมถึงการตอบข้อความ นอกจากนี้เราประมวลผลข้อมูลเมื่อจำเป็นเพื่อปฏิบัติตามหน้าที่ทางกฎหมาย เราไม่ขายข้อมูลส่วนบุคคล หรือใช้การติดต่อเกี่ยวกับเว็บไซต์เพื่อตัดสินใจโดยอัตโนมัติล้วน ๆ ที่มีผลทางกฎหมายหรือผลกระทบสำคัญในลักษณะเดียวกัน

การเก็บรักษา ผู้ให้บริการ และความปลอดภัย

บันทึกการเชื่อมต่อทางเทคนิคเก็บไว้ตามข้อกำหนดด้านการดำเนินงานและความปลอดภัยของบริการโฮสติ้ง รวมถึงการแก้ปัญหาและการตรวจสอบเหตุการณ์ เราเก็บการติดต่อไว้เท่าที่จำเป็นเพื่อจัดการคำขอและข้อพิพาทหรือหน้าที่ทางกฎหมายที่เกี่ยวข้อง แล้วลบเมื่อไม่จำเป็น ระยะเวลาเก็บรักษาขึ้นอยู่กับวัตถุประสงค์ ระยะเวลาการตรวจสอบเหตุการณ์หรือข้อพิพาท และหน้าที่ทางกฎหมายที่ใช้บังคับ คุณสอบถามระยะเวลาหรือเกณฑ์ที่ใช้กับบันทึกที่เกี่ยวข้องกับคำขอของคุณได้

บริการเว็บโฮสติ้งของเราจัดการบันทึกการเชื่อมต่อทางเทคนิค GitHub จัดการข้อมูลเมื่อคุณใช้เว็บไซต์สำเนาบน GitHub Pages และ Google จัดการการติดต่อผ่าน Gmail และบริการ Search Console ผู้ให้บริการเหล่านี้อาจประมวลผลข้อมูลนอกประเทศของคุณ รวมถึงนอกเขตเศรษฐกิจยุโรป (EEA) ข้อมูลความเป็นส่วนตัวของพวกเขาอธิบายการเก็บรักษา มาตรการคุ้มครอง และวิธีโอนข้อมูลที่เกี่ยวข้อง เราจำกัดการเข้าถึงบันทึกการดำเนินงานและการติดต่อ และใช้ HTTPS สำหรับการเชื่อมต่อเว็บไซต์ แต่ไม่มีระบบใดรับประกันความปลอดภัยได้อย่างสมบูรณ์
